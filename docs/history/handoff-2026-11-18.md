# 交接说明：SAI 安卓压感（截至 2026-11-18 00:50）

## 现在能用的东西

全部在 GitHub Releases 与仓库 `dist/` 里：

| 文件 | 用途 |
|---|---|
| `Winlator-11.2-SAIPen.apk` | **已改好的 Winlator**（150 MB）。基于你手机里那个原版 APK 逐字节复制，只替换了 `classes.dex` 里十几条指令 |
| `pensender.dex` | 数位板 → UDP 发送端（`app_process` 直接跑，不用装任何 App） |
| `wintab32.dll` | 塞进 Wine 容器，让 SAI 拿到笔压 |
| `wt_pmax.txt` | 内容 `4095`，DLL 启动时读一次，决定压力上限 |

设备上**已经装了**这个补丁版（包名仍是 `com.winlator`），容器里也已经装好 `wintab32.dll`、`wt_pmax.txt` 和完整的 SAI。

## 已验证的事实

- **压感链路是真的**：数位板 → PenSender → UDP → `wintab32.dll` → SAI，实测 `recv/posted/fetched` 三个计数同步增长、`gaps=0`、延迟中位数 1 ms，最大压力值采到 2431（硬件 16383 级，映射到 4095 上限）。
- **DLL 在 Box64 下能正常加载**（`dll=loaded`、`ours=yes`、`WinTab` 握手完整、`maxPress=4095`）。
- **补丁版 APK 能启动、能进 Wine 桌面**（这就是 smali 原地改的意义：资源/原生库/assets 全是原版字节，不像之前自建 APK 那样卡在 "Starting up"）。
- **原版"拖动时不按左键"的根因已定位并改掉**：`TouchpadView.onTouchEvent` 的 `ACTION_DOWN` 分支原本只 `new Finger`，左键只在"抬起且判定为 tap"时按一次，所以拖动永远画不出线。补丁在按下瞬间就 `injectPointerMove` + `pressPointerButtonLeft`。

## 你需要做的三步

### 1. 装 SAI

在 Winlator 里把你自己合法取得的 SAI 装到容器内（完整目录，**必须包含 `init/` 文件夹和 `sai2.ini`**，只放 `sai2.exe` 会报"构成 SAI 的文件不存在"）。

### 2. 把压感桥放进容器

容器的 `drive_c` 在：

```
/data/data/com.winlator/files/rootfs/home/xuser-1/.wine/drive_c
```

```bash
adb push wintab32.dll /data/local/tmp/
adb push wt_pmax.txt  /data/local/tmp/
adb shell su -c 'cp /data/local/tmp/wintab32.dll /data/data/com.winlator/files/rootfs/home/xuser-1/.wine/drive_c/windows/system32/'
adb shell su -c 'cp /data/local/tmp/wt_pmax.txt  /data/data/com.winlator/files/rootfs/home/xuser-1/.wine/drive_c/'
adb shell su -c 'chown 10310:10310 /data/data/com.winlator/files/rootfs/home/xuser-1/.wine/drive_c/windows/system32/wintab32.dll'
```

（`10310` 是 `com.winlator` 的 uid，若重新安装过 App 需用 `stat -c %u /data/data/com.winlator` 重新确认。）

**DLL 覆盖**：在容器的 `user.reg` 里加一行，或直接用环境变量
`WINEDLLOVERRIDES=wintab32=n,b`。注册表写法（文件 `.wine/user.reg`）：

```
[Software\\Wine\\DllOverrides]
"wintab32"="native,builtin"
```

### 3. 打开 SAI 的 WinTab

SAI 菜单 **Other → Options → Pen Tablet**，选 **`Use WinTab API`** → OK → **重启 SAI**。

只有开了这个，SAI 才会去加载 `wintab32.dll`。验证方式：容器里应出现
`drive_c/wt_status.txt`，内容里 `open=1`。

### 4. 启动发送端

```bash
adb push pensender.dex /data/local/tmp/
adb shell su -c 'CLASSPATH=/data/local/tmp/pensender.dex app_process /system/bin PenSender /dev/input/event8 1280 720 4095 250'
```

参数：`<设备> <容器宽> <容器高> <pmax> <最大发送Hz> [屏幕长边] [屏幕短边] [是否注入按下=1]`

数位板设备号可能变（`getevent -pl` 里找带 `ABS_PRESSURE` 的那个）。

## 已知问题 / 还没做完的

1. **容器崩溃**：最后几次操作里容器崩了。我的操作（反复 force-stop、整包还原前缀、覆盖 `.wine`）大概率是原因，不是补丁本身——补丁只改了 `TouchpadView` 里按下时的行为，不影响容器启动。建议直接重启 App 再进容器。
2. **"按下"用的是 `input motionevent` 注入**，每次笔画起止各一次进程调用（约几十毫秒）。如果觉得起笔有延迟，正确做法是在补丁里改成常驻 UDP 监听，而不是每笔 spawn 一次。
3. **压感曲线**要调：硬件 16383 级 → 我们的 4095 → SAI 笔刷的最小尺寸/笔压曲线，三层相乘。先确认 SAI 里笔刷的 **Min Size 不是 100%**。
4. **倾斜/橡皮**没做（evdev 里 `ABS_TILT_X/Y`、`BTN_TOOL_RUBBER` 都有，只是没转发）。
5. **16 KB 对齐告警**：补丁版是 debug 来源，系统会弹一次兼容性提示，点"确定"即可运行。
